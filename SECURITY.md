# Security

Please report security problems privately through GitHub's
**[private vulnerability reporting](https://github.com/alex-nax/relith/security/advisories/new)**
for this repository, not in a public issue.

Only download ReLith from this repository's
[Releases](https://github.com/alex-nax/relith/releases) page. A release's files are the only
official builds; anything else calling itself ReLith is not from this project.
